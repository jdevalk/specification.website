Four pages cover the infrastructure underneath a website: [IPv6 reachability](/spec/resilience/ipv6/) for web and name servers, [RPKI route origin validation](/spec/security/rpki/), [DANE for HTTPS](/spec/security/dane/) (optional, since no mainstream browser checks it), and [TLS configuration hardening](/spec/security/tls-configuration/), which extends the HTTPS checklist with the individual parameters scanners test.
