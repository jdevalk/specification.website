---
title: "Clear-Site-Data is not Baseline"
date: "2026-11-27"
type: changed
relatedSlugs: [clear-site-data]
---

[Clear-Site-Data](/spec/security/clear-site-data/) no longer claims the header is Baseline widely available: web-features moved it back to limited availability in April 2026. The page now says which directives work everywhere (`"cookies"`, `"storage"`), which are partial or Chromium-only, and drops `"executionContexts"` from the sign-out example because no current browser implements it.
