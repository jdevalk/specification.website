Added a page on [CSS subgrid](/spec/foundations/subgrid/) — the `grid-template-columns: subgrid` / `grid-template-rows: subgrid` value (CSS Grid Layout Module Level 2) that lets a nested grid inherit its parent's tracks, so cards, form rows, and list items line up across the whole layout without magic numbers or JavaScript measurement. Subgrid has been Baseline widely available across Chrome, Edge, Firefox, and Safari since September 2023.
