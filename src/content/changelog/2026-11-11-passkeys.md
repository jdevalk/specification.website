The spec now has a [passkeys page](/spec/security/passkeys/): discoverable WebAuthn credentials as the primary sign-in, with Conditional UI autofill, server-side verification via a vetted FIDO2 library, an explicit RP ID, and the Signal API to keep credential managers in sync. Prompted by a review of Google's Modern Web Guidance, whose seven passkey guides exposed the gap next to the existing accessible-authentication and /.well-known/webauthn pages.
