Added a page on [`/.well-known/oauth-protected-resource`](/spec/well-known/oauth-protected-resource/) (RFC 9728), the OAuth 2.0 metadata document that tells clients which authorisation server issues the tokens a protected API accepts. It is marked `optional` — it applies only to sites exposing an OAuth-protected resource — and it is the well-known URI the Model Context Protocol's authorization spec now requires of authenticated MCP servers.
