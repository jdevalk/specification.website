The spec now has an [Agent Name Service](/spec/agent-readiness/agent-name-service/) page: DNS-anchored, versioned agent identity with a transparency log, the three proofs (identity, current status, possession), and the mTLS and DPoP authentication methods — with the draft status stated up front. ANS launched as a Linux Foundation project on 10 November 2026.
