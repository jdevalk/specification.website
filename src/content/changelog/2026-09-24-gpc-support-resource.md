The Global Privacy Control page covered the `Sec-GPC` header but never the support resource the same specification defines, so [`/.well-known/gpc.json`](/spec/well-known/gpc-json/) now has a page of its own. It is `optional`, and it leads with the confusion worth naming: the file declares that an origin honours GPC, it is not how an origin honours GPC.
