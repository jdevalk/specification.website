New **Security** topic on the [Reporting API](/spec/security/reporting-endpoints/) — the `Reporting-Endpoints` response header that names collectors for the browser's structured reports: CSP and COOP violations, permissions-policy breaches, deprecations, interventions, and crashes. It supersedes the legacy `Report-To` header and `report-uri` directive; status: recommended.
